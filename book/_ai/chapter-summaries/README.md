# Chapter Summary Files

Each file in this directory is a compact continuation note for one book chapter. These summaries are designed to be read by a new AI before it continues writing, so they should remain factual, short, and limited to material that has actually been written.

Summary filenames use the same three-digit chapter number and slug as their matching chapter file, followed by `-summary.md`.

Use the [global continuation state](../CONTINUATION_STATE.md) to find the current chapter and exact next section.
