# The Complete Modern PHP Engineering Book

This directory contains the Markdown book generated from the outline in [SKELETON.md](../SKELETON.md).

The chapters are grouped by volume and use YAML front matter so a future static-site generator can build navigation, metadata, and progress views. The _ai/ directory contains authoring state and is intended to be excluded from the published site.
