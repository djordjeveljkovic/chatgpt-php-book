# The Complete Modern PHP Engineering Book

This repository contains a long-form Markdown book about modern PHP engineering, from PHP fundamentals and the Zend Engine to databases, architecture, distributed systems, and production operations.

## Book

Start at the [book index](book/README.md). Chapters are grouped into 21 volumes under `book/volumes/` and use YAML front matter for future static-site publishing.
